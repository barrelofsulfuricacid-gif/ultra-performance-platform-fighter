## Earlier cross-target checkpoint method

Two clean-tree milestone runs were taken on each local target. Every available
scenario used 15 calibrated samples targeting at least 100 ms of work per
sample. Run 1 established an isolated same-target baseline; run 2 compared
against that unchanged-workload baseline through the canonical SQLite-backed
regression gate.

The WSL series used GCC 13.3 on Linux x86-64 under WSL2. The native Windows
series used MSVC 19.44.35228 on Windows x86-64. The portable MSVC environment
invoked the canonical `pf_benchmarks` product directly because the convenience
PowerShell launcher expects a Visual Studio Installer registration. The same
executable self-test, schema, scenario preflights, calibrated sampler,
environment fields, SQLite history, and graph generation remained active.

Commit `1df6923` changes only the profile build option, presets, profile driver,
and profile documentation relative to `441feef`; it does not change simulation,
content, or benchmark scenario source. Cross-platform rates are reported as
separate evidence and are never compared to one another.
