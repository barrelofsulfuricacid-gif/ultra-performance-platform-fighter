All 10 comparisons are compatible in each current run. Both record zero
invalid comparisons, zero suspected regressions, and zero confirmed
regressions. The first current run ranges from -8.09% to +0.67% in raw medians;
the low RL-batch sample also has a 6.22% measured noise floor and remains well
inside its 18.65% meaningful threshold. The same-commit repeat recovers 6.21%
on that scenario and remains compatible. The database independently records
2,472 state bytes and a 771-byte checkpoint for every scenario.

The provisional unpacked orientation implementation produced a 635-byte
payload and 775-byte checkpoint. Because 635 bytes forces one additional
SHA-256 compression block while 631 bytes does not, exact parent/current runs
showed checkpoint-path regressions. The final format packs tech direction and
prone orientation into one canonical byte per player, restoring the 631-byte
payload; the qualified table above demonstrates that the regression is gone.

`df35269387c0c62e8505c8cf7fb6a14033126fe9c4dc2dfec482abbb69ac5c0b`.
WSL used Tracy's supported timer fallback. `perf` was not installed, so no
platform-profiler claim is made; unsampled Windows results above remain the
throughput evidence.
