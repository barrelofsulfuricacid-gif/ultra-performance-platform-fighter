# D1-A roster coverage matrix

## Scope

The release roster must contain one original mechanical counterpart for every
playable SSBM fighter/form. Reference names below are internal requirements
labels only and must never become shipped character names, assets, lore, or
marketing.

Counterpart IDs remain neutral until the original setting and character bible
are approved. “Preserve” means functional and matchup identity, not copied frame
data, animation, geometry, formulas, audiovisual expression, or source data.

## Cross-roster rules

- F23/F26 are two complete forms linked by an in-match transformation system;
  neither may be an unfinished menu-only variant.
- F08 is one selection controlling two independently simulated bodies.
- Clone-derived pairs preserve their meaningful mechanical differences and do
  not share data merely to reduce implementation work.
- Seeded randomness is allowed only where matchup identity requires it. Replays,
  rollback, and server verification must reproduce every result.
- Each counterpart receives original proportions and independently tuned
  collision geometry. Reference silhouettes, costumes, animations, VFX, voice,
  and iconography are prohibited.
- Under the 2026-08-03 owner-approved exception, numeric gameplay tables and
  formulas may inform implementation when field-level provenance and conversion
  records are committed. Extracted game files, executable code, ripped
  hitboxes, and expressive assets remain prohibited repository inputs.

## Completion gate

D1-A roster coverage is complete only when all 26 rows:

- Have a playable original counterpart.
- Preserve the listed functional identity and counterplay.
- Have complete original presentation and provenance.
- Pass local, 2v2, CTF, replay, rollback, RL, and matchup smoke tests.
- Pass formal pre-release IP/originality review.
